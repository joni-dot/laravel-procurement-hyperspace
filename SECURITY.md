# Security policy

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue, discussion or pull request.

1. Go to the repository's [Security tab](https://github.com/joni-dot/laravel-procurement-hyperspace/security).
2. Click **Report a vulnerability**.
3. Fill in the form. Only you and the maintainers can see the report.

If you are not sure whether something is a security problem, report it privately anyway.

## What to include

- What the problem is and what an attacker could do with it.
- Steps to reproduce it: a role, a request or a short script is enough.
- The version you tested: a commit hash, or the date if you used a hosted instance.
- Any idea you have for a fix (optional).

Please test only against your own installation. Do not access other people's data, run denial-of-service tests or send spam to hosted instances.

## What happens next

- We acknowledge your report, normally within a few working days.
- We confirm the problem and keep you updated as we work on it.
- We fix it **quietly first**. The fix is released and hosted instances are updated before anything is made public.
- Only then do we publish a GitHub security advisory. We credit you in it unless you would rather stay anonymous.

Please keep the details private until the advisory is published.

## Supported versions

Only the latest `main` branch gets security fixes. If you host your own copy, update to the latest `main` to receive them.
